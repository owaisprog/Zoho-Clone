# Frontend - Zoho Clone

**Status:** Directory initialized during P0.01. Application scaffolding is scheduled for P3.

## Locked technology choices

- Next.js and React
- TypeScript
- Tailwind CSS
- shadcn/ui and accessible Radix primitives
- REST API client for the Express.js backend
- Responsive, permission-aware layouts

## Planned responsibilities

1. Marketing website and authentication screens.
2. Organization onboarding, switching, application launcher, settings, and subscription UI.
3. CRM, merchant operations, and every later business application's frontend pages.
4. Reusable tables, forms, dashboards, dialogs, loading/empty/error states, and accessibility patterns.
5. Frontend unit/component tests and Playwright end-to-end tests.

**Not yet created:** package.json, src/, routes, dependency lockfile, environment files, deployment configuration.

Do not place API secrets in frontend code. The backend is the authorization and business-rule authority.
