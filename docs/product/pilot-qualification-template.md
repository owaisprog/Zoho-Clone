# P0.09 — Pilot Selection Checklist and Decision Record (Blank)

**Public repository contains a blank template only.** Personal details, merchant names, unpublished contracts and respondent notes belong to the product owner's private access-controlled records.

## Candidate qualification
- [ ] The company is a real ISO, merchant-services business or relevant POS reseller.
- [ ] Budget authority and daily champion verified; no fabricated names.
- [ ] A recent concrete operational pain exists and its impact is explained.
- [ ] Existing NMI/processor/CRM tools and what they already do well recorded.
- [ ] Tracking-only MVP useful without live processor onboarding, KYC or residual payout.
- [ ] Pilot can run on synthetic/authorized sanitized records under separate terms.
- [ ] Data retention, access and prohibited-field restrictions understood.
- [ ] Clear success metric and procurement conditions defined.
- [ ] Written next action exists and partner has agreed to follow-up.
- [ ] Security/legal checks are complete before any real merchant data.
